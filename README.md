# Machin Construction Depot

Proyecto monorepo para la plataforma de retail de materiales de construccion.

## Stack Tecnologico
- Next.js (Web Apps)
- NestJS (API)
- Turbo (Monorepo management)
- Tailwind CSS
- Prisma (ORM)

## Requisitos
- Node.js >= 22
- pnpm

Nota: El proyecto requiere Node.js >= 22 para funcionar correctamente.
