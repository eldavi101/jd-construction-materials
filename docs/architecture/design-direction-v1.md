# Direccion de Diseno v1 - J&D Construction Materials

## Objetivo Visual
Construir una experiencia de e-commerce profesional, rapida y confiable, inspirada en grandes retailers (claridad, jerarquia, conversion), pero con identidad propia enfocada en construccion.

## Principios de UX
1. Claridad primero: categorias y buscador siempre visibles.
2. Conversion rapida: menos pasos entre producto y checkout.
3. Confianza operacional: stock visible, tiempos de entrega claros, metodos de pago destacados.
4. Navegacion util: filtros simples, breadcrumbs, comparacion basica de productos.

## Estilo UI
- Tono: retail moderno, limpio, tecnico, directo.
- Densidad: media, optimizada para escritorio y movil.
- Tipografia propuesta: Manrope (UI) + Archivo (titulares).
- Bordes: suaves (10-14px) con cards limpias.
- Sombras: discretas para separar capas sin ruido visual.

## Componentes Clave
1. Header sticky con buscador grande y acceso rapido a carrito/cuenta.
2. Mega menu por categorias de materiales.
3. Grid de productos con estado de inventario.
4. Tarjeta de producto con CTA primario visible.
5. Checkout de 1 pagina (MVP) con resumen fijo.
6. Admin dashboard con KPIs de ventas, ordenes, inventario bajo.

## Home Structure MVP
1. Hero comercial con CTA.
2. Bloques de categorias destacadas.
3. Productos populares.
4. Beneficios (entrega, stock real, soporte).
5. Marcas o aliados.
6. FAQs SEO/GEO.
7. Footer completo con datos legales.

## Notas SEO + IA
1. Evitar textos genericos, priorizar descripciones tecnicas concretas.
2. FAQs por categoria y por producto.
3. Schema para Organization, Product, BreadcrumbList, FAQPage.
4. Estructura de entidades localizadas (Miami/Florida).
