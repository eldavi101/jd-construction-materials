# Input Necesario - Siguiente Paso

Para continuar con implementacion real de apps (Next/Nest), necesito:

1. Instalar Node.js LTS y pnpm (ver guia en docs/SETUP_REQUIRED_FROM_USER.md).
2. Confirmar estos 5 puntos de negocio/diseno:
   - Nombre comercial exacto a mostrar.
   - Ciudad/zona de entrega inicial.
   - Idioma inicial (ES o ES/EN).
   - Color principal de marca (si no hay, se usa #0053A0).
   - Metodo de envio MVP (retiro, envio local por zonas, o ambos).

Cuando lo tengas, responde con:
- "listo"
- y los 5 puntos en una sola lista.
