# Guia de Preparacion del Sistema

Siga estos pasos para configurar su entorno en Windows:

1. Instale la version LTS de Node.js (v22 o superior) desde [nodejs.org](https://nodejs.org/).
2. Abra una terminal y verifique la instalacion:
   ```bash
   node -v
   npm -v
   ```
3. Instale pnpm globalmente:
   ```bash
   npm install -g pnpm
   ```
4. Una vez completado, responda con: **listo**
